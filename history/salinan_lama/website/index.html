Write a script.
Ship a fast .exe.

nrxl is a small, strictly typed language. Run your file straight away while you work on it, then build the same file through C into one .exe that needs nothing else.

Get nrxl Read the syntax

Same file, two speeds

While you write, nrxlang run starts instantly. When you are done, nrxlang build turns int, double, and bool variables into plain C variables and number-only functions into real C functions. The syntax does not change.

Measured on 4 November 2026 on an Intel Xeon E3-1220 v2. Wall time including process start, best of 3 runs (script) and 5 runs (.exe). Programs: bench_fib.nrxl, bench_loop.nrxl.

Mistakes stop it before it starts

Look at the output: starting... never prints. nrxl checks the whole file first, including functions that are never called, and refuses to run code that is certainly wrong.

  • A variable keeps the kind it was created with. 5 is an int, 2.5 is a double.
  • Lists and maps hold one kind of item. Mixed data gets a type.
  • Every error has a code, like E0229, and reads in English or Indonesian with errlang.

Your own types

Fields have fixed types and defaults. Methods reach the object through own. A misspelled field is an error before the program runs.

Maps that start at zero

be count[w] += 1 works on a new key: it starts from the empty value of the map's kind. Text and values written side by side join without +.

Windows DLLs, directly

Declare the C function and call it. nrxl checks that the DLL and the function exist before the program starts. Buffers and callbacks cover structs and functions like qsort.
