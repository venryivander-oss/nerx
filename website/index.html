Write a script.
Ship a fast .exe.

nerx is a small, strictly typed language. Run your file straight away while you work on it, then build the same file into one .exe that needs nothing else. Nothing else to install.

Get nerx Read the syntax

Same file, two speeds

While you write, nerx run compiles to a temporary .exe, runs it, and deletes it. When you are done, nerx build keeps the .exe. Either way the built-in compiler (nrxc) writes x64 machine code straight into the file. No VM, no interpreter. The syntax does not change.

Close to C on number crunching

The same program written in C and in nerx, both compiled to an .exe. In loops that add and take remainders, nerx lands within about 10% of C. Function calls are the weak spot: a recursive fib is roughly on par with unoptimized C, and about 4x slower than gcc -O2, which rewrites the recursion.

Mistakes stop it before it starts

Look at the output: starting... never prints. nerx checks the whole file first, including functions that are never called, and refuses to run code that is certainly wrong.

  • A variable keeps the kind it was created with. 5 is an int, 2.5 is a double.
  • Lists and maps hold one kind of item. Mixed data gets a type.
  • Every error has a code, like E0229, and reads in English or Indonesian with errlang.

The compiler is written in Nerx

nrxc is the Nerx compiler, and it is itself a Nerx program. It writes the Windows .exe or Linux file directly, so you do not need any other compiler or a runtime next to your program.

  • It compiles itself: the compiler it builds is byte-for-byte the same as the one that built it.
  • Every library (window, 3D, json, http, sound, files, and more) is written in nerx too.
  • Output and error messages match the original interpreter (kept in history/), checked on 84 test programs and 105 error cases.

Your own types

Fields have fixed types and defaults. Methods reach the object through own. A misspelled field is an error before the program runs.

Maps that start at zero

be count[w] += 1 works on a new key: it starts from the empty value of the map's kind. Text and values written side by side join without +.

Windows DLLs, directly

Declare the DLL function and call it. nerx checks that the DLL and the function exist before the program starts. Buffers and callbacks cover structs and functions like qsort.

Build from source

nrxc, the compiler inside nerx.exe, builds itself from a seed copy of nrxc.exe that is kept in the repository. The original interpreter and earlier code are archived in history/.

Then

nerx run file.nrx runs a script. nerx build file.nrx (or nerx file.nrx) makes file.exe. The full language, every built-in function, and every library are on the syntax page.

The script installs to ~/.local (or /usr/local as root). Remove it with ./install.sh --uninstall. To verify your download, run sha256sum on the file and compare it with the SHA-256 above.

Build from source

The compiler builds itself with the nerx you installed above, from the source in src/nrxc.nrx.

Then

nerx run file.nrx runs a script. nerx build file.nrx makes a Linux program named file; nerx build file.nrx -o file.exe makes a Windows one. The full language, every built-in function, and every library are on the syntax page.

macOS is not supported yet. It is planned after Linux. Until then, use Windows or Linux.
